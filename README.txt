RW 08 KAMPUNG CIUTARA - PROTOTIPE APLIKASI
============================================

Isi:
- Beranda
- Pengumuman
- Surat Pengantar + formulir pengajuan
- Data Warga + pencarian
- Iuran Warga (struktur awal)
- Kegiatan RW
- Laporan/Aduan + formulir
- Informasi RW
- Login pengurus demo

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Untuk menjadi APK/online, project ini perlu dipasang ke hosting atau dibungkus dengan Android WebView/Capacitor.

CATATAN:
Ini adalah prototipe frontend. Data masih tersimpan di browser (localStorage).
Untuk penggunaan warga sungguhan, tahap berikutnya adalah backend/database, autentikasi aman,
hak akses Warga/RT/RW/Admin, penyimpanan dokumen, dan notifikasi.
